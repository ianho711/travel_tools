# 旅伴帳本

要使用 Google 試算表版，請先下載 [試算表範本](google-sheets/旅遊費用分攤_Google試算表範本.xlsx)，並閱讀 [開始使用](google-sheets/開始使用.md)。

也可下載 [啟用助手](google-sheets/啟用助手.html) 到電腦後開啟，使用「複製設定程式」按鈕；或直接開啟 [Code.gs](google-sheets/Code.gs) 複製程式。在 Google 試算表執行一次設定後，你可以編輯，旅伴可設為檢視者。

繁體中文旅遊費用分攤網頁。所有程式都在 `index.html`，沒有登入、後端、外部 API、CDN 或前端套件相依。預設為 **30 個空白名額、10 天**，不會預載假支出。

另有 [Google 試算表版本與指定 Drive 資料夾操作說明](google-sheets/開始使用.md)，適合「你編輯、旅伴共同檢視最新資料」。

## 開啟

下載 `index.html`，用現代瀏覽器開啟即可離線操作。若瀏覽器限制本機檔案的儲存功能，建議在此目錄啟動 Python 本機伺服器：

```bash
cd /path/to/travel_tools
python -m http.server 8000 --bind 127.0.0.1
```

在同一部電腦的瀏覽器開啟 `http://127.0.0.1:8000/index.html`。不需要網際網路；伺服器只提供本機檔案。離開時以 Ctrl+C 停止。

## 操作

1. 展開「統一名單」輸入姓名，可新增或刪除成員。空白姓名不計入人數；改名沿用固定 ID，不會移除紀錄。
2. 切換每日分頁，填寫費用名稱、類別、金額與代墊者，勾選實際參與者。同類費用可新增多筆。
3. 用車日勾選「當日用車」，並勾選一位或多位當日司機。司機只免當天勾選參與的油錢與租車費，餐費、停車費及其他照常分攤。
4. 總覽即時彙整各人分攤、代墊、還要付與應收回；其他費用合計包含停車費。可用「載入範例」體驗，會先確認是否取代資料。
5. 資料自動存入 localStorage；請定期「匯出 JSON」，並可用「匯入備份」還原。更換電腦、瀏覽器、檔案位置、網址或連接埠，儲存空間可能不同。清除瀏覽器資料或使用無痕模式也可能失去資料。

金額以 **0.1 元的整數**計算，再格式化顯示；不會直接累加小數金額。尾差依統一名單順序分配，例如 100 元／3 人為 33.4、33.3、33.3。金額最多一位小數、單筆上限 100,000,000 元；最多 200 個名額、100 天、每天 100 筆費用。

正金額沒有可分攤者、車資缺司機、未用車卻有車資，都會列為待處理並暫停該筆分攤。取消用車需要確認，原金額、司機、代墊與參與紀錄均保留，重新勾選用車即可恢復。未填代墊者會警告，但仍計算個人分攤。待處理費用的合法金額仍列入全部支出與已代墊，請先處理警告再結算。

匯入會檢查版本、欄位型別、ID 唯一性、成員參照及大小上限（10 MB），通過後還要確認才取代帳本；失敗不改原資料。尚未改正的不合法金額可隨備份保存，但會持續列為待處理，不計入支出。刪除有資料的成員、日期與費用，以及重設全部，都有確認步驟。

## 你編輯、大家共同檢視

按「**匯出唯讀網頁**」下載 `trip-view.html`。它內含發布當下的整趟資料，旅伴可以切換總覽與各天，但所有編輯欄位皆停用；也不讀寫檢視者的 localStorage。你繼續在原 `index.html` 編輯。

### GitHub Pages

1. 在 GitHub 的發布儲存庫建立 `docs/`，將匯出的唯讀檔案上傳為 `docs/index.html`。
2. 到該儲存庫 **Settings → Pages → Deploy from a branch**，選擇發布分支與 `/docs` 資料夾，儲存。
3. GitHub 完成發布後，將它提供的 Pages 網址分享給旅伴。
4. 你修改帳目後，再次匯出唯讀網頁並取代 `docs/index.html`；旅伴重新載入即可看到新版。這是手動發布的快照，不是即時同步。

訪客不能修改 GitHub 上的帳本，因為網頁沒有寫入 GitHub 的功能；只有持有該儲存庫寫入權限的人才能更新網站。唯讀介面不提供私人存取驗證，且 GitHub Pages 通常可公開瀏覽，**只發布你願意分享的資料**。私有儲存庫是否可使用 Pages 取決於 GitHub 方案，私有儲存庫不代表 Pages 網站也是私人。

GitHub Pages 需另行設定；儲存庫已有檔案不代表已發布網站。

### Google 雲端硬碟

可將 JSON 備份放到 Google Drive 保存，或將唯讀 HTML 傳給指定檢視者下載開啟。Google Drive 通常不會直接執行 HTML 網站；若要直接透過網址檢視互動分頁，使用 GitHub Pages。若只需要在 Drive 直接預覽，可另外分享 PDF／試算表。

## 測試

計算測試只需 Node.js 18 以上，直接測試 `index.html` 中的同一份引擎：

```bash
node --test tests/calculation.test.cjs
```

瀏覽器操作測試需 Python、Playwright 與 Chromium；測試會自行啟動本機伺服器，並將截圖與 JSON 放在系統暫存目錄，不寫入實際旅遊資料：

```bash
python -m pip install playwright
python tests/browser_test.py --browser /path/to/chromium
```

本次已在 Chromium 桌面與 390px 手機視窗實測。計算與瀏覽器的完整結果記錄於 `TEST_RESULTS.md`。環境政策阻擋 `file://`，因此直接雙擊開啟未能實測；實測使用本機 HTTP，並阻擋外部網路請求。未實測 Firefox、Safari、真實手機及 GitHub Pages／Google Drive 的實際發布。
