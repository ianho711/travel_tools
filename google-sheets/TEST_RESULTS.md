## Apps Script 資料處理：8 項程式層測試通過

使用記憶體中的 Sheets 介面替身，測試實際 `Code.gs` 函式：

1. 預設 2410 個核取方塊的設定位置。
2. 重複啟用核取方塊只改驗證規則，不清除金額、司機、代墊與參與紀錄。
3. 改姓名保留 ID；日期分頁改名後可依 sheet ID 找回。
4. 全選／取消全選只操作具名成員，空白姓名的既有紀錄保留。
5. 取消已有車資的用車會提示，取消操作後恢復用車；以事件來源日期判定。
6. 既有試算表若有其他資料，初始化停止且不覆寫。
7. 匯入未知參照、重複 ID、錯誤型別與超限資料會拒絕。
8. 同名備份分頁若是其他資料，不會覆寫。

這些測試不等於已執行 Google 服務或已在帳戶內點選核取方塊。

目前沒有 Google Drive／Sheets 寫入連線，所以沒有上傳檔案、建立 Google 原生試算表、改動共用權限，也沒有實測 Google 授權、服務呼叫及原生核取方塊 UI。

開發用重跑指令：

```bash
node --test google-sheets/script.test.cjs
python google-sheets/test_formulas.py
```
